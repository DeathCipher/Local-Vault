Before you start

  • You need a 64-bit PC running Windows 10 or 11.
  • Windows will ask for administrator approval, because the installer puts the program in Program Files.

Install

  1. Download localvault.msi (16.2 MB) and open it.
  2. Click through the welcome and license pages.
  3. On the Custom Setup page you can change the install folder with Browse. Untick Desktop shortcut if you don’t want one. The Start menu shortcut is always added.
  4. Click Install, approve the Windows prompt, then open LocalVault from the Start menu.

If Windows blocks the installer

You may see a blue “Windows protected your PC” message, or a browser warning that the file isn’t commonly downloaded. Windows shows this for every installer that isn’t code-signed with a paid certificate, whether or not the file is safe.

If you got this page from the person who built the installer, check the download first (next section), then choose More info and Run anyway.

Check your download

The checksum below identifies the exact file that was published here. If the one you compute doesn’t match, don’t install it.

3e8c807b02f218ce443426534049845136844f18ff52671badd6be4cbde45b60

Open PowerShell in the folder where you saved the file and run:

Get-FileHash .\localvault.msi -Algorithm SHA256

Or, in Command Prompt:

certutil -hashfile localvault.msi SHA256

For the strongest check, get the checksum from the person who built the installer in a message or in person, rather than only from this page.

Where your data lives

Your vault is one file: %UserProfile%\.localvault\vault.json. LocalVault keeps the previous version next to it as vault.json.bak.

To back up your passwords, copy the .localvault folder somewhere safe, or use Export, then Encrypted backup, inside LocalVault. Both are locked with your master password, so they’re only as safe as that password. Avoid the plain CSV export for backups, because it isn’t encrypted.

Update

Download the new localvault.msi and open it. It replaces the old version and leaves your vault untouched.

Uninstall

Open Settings, go to Apps, find LocalVault in the list and choose Uninstall. This removes the program only. Your vault stays in %UserProfile%\.localvault until you delete that folder yourself.
